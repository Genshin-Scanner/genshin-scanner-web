# Текущее состояние Genshin Scanner

Работают три библиотеки Bun workspace. GOOD использует схему и ключи из закреплённой ревизии Optimizer. Ядро находит карточку по цветовым областям, распознаёт отдельный кадр через переданную функцию OCR и возвращает поля для проверки. Браузерный адаптер предоставляет Tesseract-worker с локальной английской моделью.

## Проверки

После `bun install` команда `bun run check` прогоняет открытые тесты, Prettier, TypeScript и Vite-сборки. `bun run check:frames` дополнительно использует приватные PNG из `test-assets/`. Все три контрольных кадра проходят проверку набора, редкости, уровня и строк характеристик. Имя владельца цветка требует ручного сопоставления с персонажем. `bun run ocr:assets` подготавливает локальные ресурсы для сайта.
