# Текущее состояние Genshin Scanner

Ядро находит устойчивые показы предметов в английском интерфейсе и обрабатывает одиночные кадры через переданный OCR. Пакет GOOD выводит типы из закреплённой схемы Optimizer. Проверка сопоставляет уровень с основной характеристикой, а значения сабстатов — с допустимыми роллами 4★ и 5★.

Контрольный ролик длится 56,4 секунды и содержит 33 артефакта. Детектор проверен через FFmpeg на порядке всех 33 предметов и отдельно на переходах, наведении курсора и прокрутке. Для спорного чтения используется второй кадр после стабилизации панели. Три контрольных PNG проходят проверку основных полей, активных и неактивных строк.

## Проверки

- `bun install --frozen-lockfile` устанавливает зависимости рабочего пространства.
- `bun run check` запускает тесты, Prettier, TypeScript и сборку.
- `bun run check:frames` распознаёт три приватных PNG. `bun run check:video` сверяет выбор кадров с локальными эталонами, для декодирования используется FFmpeg.
