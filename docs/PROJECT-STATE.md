# Текущее состояние Genshin Scanner

Реализован локальный путь от записи инвентаря до GOOD v3. Сайт ищет показы английских карточек 4★ и 5★, отображает миниатюры и таймкоды, предлагает проверить спорные поля и позволяет исключить предмет перед экспортом. Файлы OCR поставляются со статическим сайтом.

## Запуск

Из корня проекта выполнить `bun install --frozen-lockfile`, затем `bun run dev`. Vite выведет локальный адрес. Для сборки статического сайта выполнить `bun run build`. Результат для размещения находится в `apps/web/dist/`. Публикация на GitHub Pages пока не выполнялась.

## Проверки

| Команда                        | Назначение                                                                                                                                                                                                                                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bun run check`                | Открытые регрессионные тесты, Prettier, TypeScript, сборки трёх библиотек и сайта                                                                                                                                                                                                                       |
| `bun run check:frames`         | Локальный OCR трёх приватных контрольных PNG                                                                                                                                                                                                                                                            |
| `bun run check:video`          | FFmpeg и покадровая сверка последовательности детектора с 33 отдельными PNG                                                                                                                                                                                                                             |
| `bun run check:browser msedge` | Проверка production-сборки через UI, включая отмену, исправление, исключение и скачивание. Также принимает `chromium`, `firefox` и `webkit`. Нужны Node с поддержкой TypeScript, установленный браузер, собранный сайт, приватный ролик и локальная ручная разметка `test-assets/expected-private.json` |

Исходная запись 1920×1200 длится 56,4 секунды. В Edge, Chromium и Firefox обнаружены 33 предмета, 7 из них потребовали просмотра. После исправлений экспорт во всех трёх браузерах совпал с независимой ручной разметкой по каждому проверяемому полю. Импорт синтетического артефакта из экспортёра проверен в официальном Genshin Optimizer 10.40.0 через обычный интерфейс базы.

Edge также прошёл проверку на производной записи 1920×1080 с полями по краям. В этом файле на проверку попали 14 из 33 предметов. Для полноценной проверки компоновки игры при 16:9 нужна запись, сделанная в этом режиме. Windows-сборка Playwright WebKit не декодировала два тестовых H.264-файла. Для подтверждения поддержки Safari нужен прогон на macOS.

На записи из трёх повторов версии 16:9 (2 минуты 49 секунд) Edge нашёл 99 предметов за 260 секунд. После проверки 42 карточек экспорт совпал с эталоном для всех 99. Один замер суммарного рабочего набора процессов тестового Edge во время этого прогона дал 807 МиБ. Сюда входит сам браузер, а значение не является измерением пика.

## Компоненты

`@scanner/core` принимает пиксели и функцию OCR и собирается без типов DOM. `@scanner/good` предоставляет типы и валидацию на основе закреплённой схемы Optimizer и его таблиц роллов. `@scanner/browser` добавляет последовательное чтение локального видео, отмену и OCR-worker. Язык, раскладка и выделение показов передаются через профиль. Пользовательский интерфейс находится в `apps/web`.
