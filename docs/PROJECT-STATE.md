# Текущее состояние Genshin Scanner

Проект находится на этапе проектирования v1. В репозитории зафиксированы [архитектура и критерии приёмки v1](v1-ARCHITECTURE.md), [правила разработки](../AGENTS.md) и исключение приватных материалов из Git. Пакеты, интерфейс сайта и автоматические тесты предстоит реализовать.

## Исходные данные

В предварительном эксперименте игрок проверил три кадра из записи H.264 в Genshin Optimizer. Все три распознаны корректно. Локальная папка `test-assets/` содержит контрольные PNG и ролик `count-33.mp4` на 33 предмета. Эти материалы доступны в рабочей копии автора.

## Проверки

Для текущего коммита с документацией используются `bun test`, Prettier для Markdown и проверка подготовленного diff. Пакетные команды тестирования и сборки появятся вместе с кодом.

## Ближайший этап

Создать Bun-workspaces и воспроизвести результаты Optimizer для пера +0, четырёхзвёздочных часов и цветка +20. Следующая проверка после этого этапа — получить 33 показа предметов из контрольного ролика в правильном порядке.
